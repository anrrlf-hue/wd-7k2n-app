# 사주 궁위론 통변 Skill

be-realdeveloper/saju (MIT License, https://github.com/be-realdeveloper/saju)의
공개 원칙 중, 이 프로젝트(saju-app)의 GAP에 해당하는 "근거 사전 + 궁위론"
구조를 참고해 정리한 개발용 Skill이다. 원본은 Claude Code Skill로 배포되는
18장 평생사주 리포트용이며, 이 파일은 그중 재물/성향 해석에 관련된 부분만
saju-app 자체 데이터 구조(SajuFacts)에 맞춰 재정리한 것이다 — 원본 코드를
그대로 복사한 것이 아니라, 원본이 공개한 "통변 원칙" 구조를 이 프로젝트의
필드명에 맞게 재구성했다.

## 원칙 1: 근거 사전 (raw 값 → 생활 언어)

사주 계산 라이브러리(ssaju)가 반환하는 원문 값을 그대로 노출하지 않는다.
항상 다음 매핑을 거쳐서 문장에 쓴다.

- 신강신약(strong/weak/neutral) → "기운이 강한 편/약한 편/중화에 가까운 편"
- 십성 그룹:
  - 비겁(비견·겁재) → "직접 경쟁·실행하는 힘"
  - 식상(식신·상관) → "만들어내고 표현하는 활동력"
  - 재성(편재·정재) → "재물을 직접 다루는 감각"
  - 관성(편관·정관) → "조직·규율 안에서 신뢰를 쌓는 힘"
  - 인성(편인·정인) → "정보를 모으고 신중하게 판단하는 힘"
- 12운성 정점(건록·제왕) → "기운이 정점에 달한 자리, 기회를 힘 있게 받아내는 조건"
- 없는 오행(원국에 0개인 오행) → "그 기운이 필요할 때 외부에서 채워야 하는 공백"

## 원칙 2: 궁위론 (같은 글자, 다른 자리 = 다른 의미)

같은 십성이라도 연주/월주/일지/시주 중 어디 있는지에 따라 해석 영역이
달라진다. saju-app에서는 이 프로젝트의 GAP으로 자체 구현했다
(src/lib/saju-labels.ts의 pillarLifeAreaLabel, src/lib/free-report-mock.ts의
궁위 기반 분기).

| 자리 | 생활 영역 |
|------|-----------|
| 연주(year) | 어릴 때 / 가족·기반 |
| 월주(month) | 사회생활 / 직업 활동 |
| 일지(day) | 나 자신 / 가장 가까운 관계 |
| 시주(hour) | 말년 / 실행한 결과가 드러나는 자리 |

예: 식상이 월주에 있으면 "실제 사회생활·업무에서" 그 활동력이 두드러진다고
쓰고, 일지에 있으면 "본인 성향 자체에서" 두드러진다고 쓴다 — 같은 "식상
2개"라는 사실이라도 위치에 따라 다른 문장이 나와야 한다.

## 원칙 3: 글쓰기 순서

결론(생활 언어) → 구체적 행동/장면 → 자기확인 장치 → 전문용어 근거(맨 마지막).
전문용어로 문장을 시작하지 않는다("일간이 ~라서"로 시작 금지).

## 이 Skill의 실제 사용 범위

saju-app에서는 이 원칙을 **런타임 라이브러리로 import하지 않는다** —
free-report-mock.ts는 결정론적 TypeScript 코드로 이 원칙을 직접 구현한다.
이 SKILL.md는 그 코드를 작성/리뷰하는 개발 단계에서 참고하는 설계
문서다. `DEVELOPMENT_SKILL_USED` / `RUNTIME_LIB_USED`를 구분해서 보고할 것.
