# Customer hand observation output check

기준 fixture `leftReadingFixture`에서 고객용 `buildPalmCustomerPassages`의 실제 결과를 확인했다.

- 기존 결과: 두뇌선·감정선·생명선 본문만 존재하고 손가락 비율은 범위 고지에만 존재
- 현재 결과: `handOverview`가 추가되어 손 전체 형태를 별도 관찰 문단으로 표시
- 내부 검수값: 손바닥 폭/길이 `0.61`, 중지/손바닥 길이 `0.95`, 검지·약지 관계
- 고객 문단에는 수치나 투영비를 노출하지 않고 `손바닥이 세로로 길게`, `중지가 손바닥에 비해 길게`, `검지가 약지보다 길게 보입니다`처럼 관찰 가능한 자연어만 표시
- 문단에는 성격·적성·건강·미래 판단이 아니라 사진에서 확인한 형태라는 한계를 함께 표시
- 휘거나 겹친 손가락은 측정에서 제외한다고 고지

따라서 손가락 passage를 성격 풀이로 되살리지는 않았지만, 손 전체 관찰 정보가 고객 화면에서 사라지지 않는다. 실제 검출 path가 없는 운명선·태양선·재물선은 이 문단에도 섞지 않는다.
