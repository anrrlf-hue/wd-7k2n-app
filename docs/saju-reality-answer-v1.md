# 사주 현실답변 V1 — PRODUCT / ENGINE CONTRACT

상태: 설계 기준서  
목적: 기존 사주·손금 자산을 버리지 않고, "풀이"를 "현실의 다음 행동"으로 연결하는 유료 상품 엔진을 만든다.

## 1. 상품 정의

상품명(작업명): **사주 현실답변**

한 줄 약속:

> 궁금한 것 하나를 사주로 풀고, 지금 현실에서 무엇을 확인하고 어떻게 움직일지 정리한다.

판매하는 것은 더 긴 사주 문장이 아니다.

판매 가치:

1. 사용자의 질문을 정확히 한 개의 결정점으로 좁힌다.
2. 현재 보유한 사주/대운/손금/자가응답 중 질문과 관련 있는 근거만 고른다.
3. 반복 패턴과 주의할 선택을 설명한다.
4. 오늘부터 실행할 현실 행동 3개를 준다.
5. 사주로 알 수 없는 현실 변수는 따로 분리한다.
6. 다음에 다시 판단할 기준을 준다.

## 2. V1 질문 영역

V1은 아래 6개만 지원한다.

- 연애·결혼
- 취업·이직
- 직장·사업
- 돈·재물
- 인간관계
- 생활·건강

사용자는 버튼으로 영역을 골라도 되고 자유질문을 입력해도 된다.
자유질문은 내부에서 6개 중 하나로 분류한다.

질문 분류만 하면 안 된다. 반드시 **결정점**을 뽑아야 한다.

예:

- "이직운 있어요?" → "퇴사부터 할지, 재직 상태에서 다음 직장을 준비할지"
- "재회할까요?" → "연락을 다시 시도할지, 관계를 정리할지"
- "사업해도 돼요?" → "지금 바로 시작할지, 검증 단계를 먼저 둘지"

## 3. 유료 결과 고정 순서

모든 영역은 같은 뼈대를 쓴다.

1. **핵심 답변**
2. **왜 지금 이 고민이 커졌는가**
3. **반복하기 쉬운 패턴**
4. **지금 피할 선택**
5. **지금 우선할 선택**
6. **현실 행동 3가지**
7. **시기 / 다시 판단할 때**
8. **사주만으로 알 수 없는 현실 확인사항**
9. **사용한 근거**

분야마다 별도 앱을 만들지 않는다.
공통 Reality Answer Engine 위에 분야별 규칙을 얹는다.

## 5. 현재 없는 핵심 엔진

### A. Question Parser
입력:
- 사용자 자유질문

출력:
- domain
- intent
- decisionPoint

### B. Evidence Selector
질문 영역에 따라 필요한 사실만 선택한다.

예:
- 취업/이직: 관성·식상·비겁, 직업 궁위, 현재/다음 대운, 직업 성향, 두뇌선
- 돈: 재성·식상, 재성 궁위, 현재/다음 대운, 사용자의 실제 돈 고민
- 관계: 비겁/관성/인성 등 관련 원국 신호, 관계 자기응답, 현재 흐름
- 생활·건강: 생활 패턴과 흐름까지만. 질병 진단 근거로 사용하지 않음

### C. Decision Engine
다음 순서로 출력한다.

QUESTION
→ RELEVANT FACTS
→ INTERPRETATION
→ RISK PATTERN
→ REALITY CHECK
→ CHOICE
→ 3 ACTIONS
→ RECHECK POINT

## 6. 매우 중요한 TRUE GAP — 정밀 시기

현재 프로젝트에 확실히 있는 것은 **현재/다음 대운 중심의 시기 데이터**다.

따라서 V1에서:
- 특정 월
- 특정 날짜
- "올해 11월에 반드시 된다"
같은 정밀 시기를 임의 생성하면 안 된다.

유료 상품에서 연도·월 단위 타이밍을 핵심 가치로 팔려면 별도 **세운/월운 계산 레이어**를 검증하여 추가해야 한다.

그 전까지 출력의 시기 정확도 표시는 `daeun_only`다.

이 GAP을 숨기지 않는다.

## 7. 돈 받을 수 있는 답변의 합격 기준

### PASS
- 사용자 질문에 바로 답한다.
- 사주 설명보다 현실 결정이 앞에 나온다.
- 사용자의 실제 선택지가 드러난다.
- 행동 3개가 오늘/이번 주에 실행 가능하다.
- 각 행동에 완료 기준이 있다.
- 사주로 모르는 것은 모른다고 분리한다.
- 근거가 질문과 직접 관련 있다.
- 같은 질문이어도 원국/대운/손금/자가응답이 달라지면 결과가 달라진다.

### FAIL
- "운이 좋습니다", "기회가 옵니다"로 끝남.
- 모든 사람에게 적용되는 뻔한 조언.
- 질문과 관계없는 사주 지식 나열.
- 상대방 마음을 사주만으로 확정.
- 합격/취업/결혼/투자수익 같은 외부 결과를 확정.
- 행동이 "긍정적으로 생각하세요", "신중하세요" 수준.
- 실제 근거에 없는 월/날짜 생성.
- 건강 질문에서 질병을 진단하거나 치료를 지시.

## 8. 분야별 필수 현실 확인

### 연애·결혼
사주로 상대방의 의사나 행동을 확정하지 않는다.
관계 상태, 실제 대화, 신뢰, 반복 갈등을 확인한다.

### 취업·이직
실제 채용공고, 연봉, 역할, 이동 가능성, 준비 수준을 확인한다.

### 직장·사업
계약조건, 고객수요, 현금흐름, 비용, 현재 역할을 확인한다.

### 돈·재물
수익률을 예측하거나 특정 금융상품 매수/가입을 지시하지 않는다.
실제 소득·부채·현금흐름이 필요한 질문은 현실 데이터 확인으로 넘긴다.

### 인간관계
상대의 의도를 단정하지 않는다.
실제로 있었던 행동과 대화 경계를 확인한다.

### 생활·건강
사주는 의료 진단이 아니다.
수면, 휴식, 일정, 스트레스, 생활 리듬 같은 행동 영역만 다룬다.
증상/질병/치료 판단은 의료 전문가 확인사항으로 분리한다.

결제 직전 무료 미리보기는 딱 하나만 준다.

잠금 뒤:
- 왜
- 반복 패턴
- 피할 선택
- 할 선택
- 행동 3개
- 시기
- 현실 확인사항
