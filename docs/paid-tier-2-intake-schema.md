# 상담 패턴 추적 — CONTENT_TRUST_CORRECTION

이 문서는 과거 유료2 추정 집계 설계를 대체한다. 결제·라우트·DB를 추가하지 않는다.
실행 가능한 스키마: `src/lib/counseling-evidence.ts`.
현재 검증·반입된 상담 패턴은 0건이며, 실제 상담 사례를 연결했다고 주장하지 않는다.

## 반입 계약

| 필드 | 내용 | 제한 |
|---|---|---|
| id / sourceRef | 비식별 패턴 ID / 승인된 원본 위치·문단 | 원본 없는 생성 금지 |
| anonymized | 식별정보 제거 확인 | true 필수; 선언만으로 비식별 검수 대체 불가 |
| context | 실제 상황 | 의견·추론과 구분 |
| observedFact | 실제 확인한 사실 | 금액의 시점·단위·범위 보존 |
| followup | 확인하지 못한 것 / 추가 질문 | 빈칸을 0으로 바꾸지 않음 |
| diagnosisPattern | 확인된 문제 유형 | 상담자 견해를 규칙으로 승격하지 않음 |
| action | 당시 제안한 행동 | 효능이 검증된 처방이라는 뜻 아님 |
| outcome | unknown 또는 confirmed | confirmed는 측정일·측정 내용·근거 위치 필수 |
| questionIds | 현 설문 필드에 대한 추적 참조 | survey-usage.ts의 실제 필드만 허용 |

## 사용 범위

질문 설계, 누락정보 확인, 진단 설명, 행동 기록 구조를 검토할 때만 참조한다.
`counselingReferences(questionId)`는 반입된 패턴 참조만 반환하며 진단값을 바꾸지 않는다.
현재 배열이 비어 있으므로 모든 참조는 빈 배열이다.

종목·상품 추천, 시장 전망, 상담자 개인 신념은 제품 규칙으로 반입하지 않는다.
사주 유형으로 과거 상담자를 소급 분류하거나 재무 문제를 설명하지 않는다.
관찰된 결과가 있어도 한 사례로 행동의 인과적 효과를 주장하지 않는다.

## 남은 실제 GAP

사용 승인이 확인된 전체 상담 원본, 비식별 검수, 사실/의견 분리, 측정 결과와 근거 검수.
이 자료가 확보되기 전에는 사례·성공률·개선 기간을 생성하지 않는다.
