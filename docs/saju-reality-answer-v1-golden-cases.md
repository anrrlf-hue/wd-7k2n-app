# 사주 현실답변 V1 — GOLDEN CASES 10

이 문서는 실제 인물 예측이 아니라 엔진 품질 검증용 가상 사례다.
괄호 속 사주 신호는 테스트 fixture가 제공한다고 가정하며, 실제 계산값이 없으면 생성하지 않는다.

## CASE 01 — 이직
질문: "요즘 회사가 너무 답답한데 지금 이직해야 할까요?"
가상 근거: 현재 대운 정관 / 다음 대운 상관 / 관성 강함 / 식상 존재 / 계획형

기대 핵심답변:
> 답답함 때문에 퇴사부터 하기보다, 재직 상태에서 다음 자리의 조건을 먼저 확인하는 편이 맞습니다.

행동:
1. 다음 직장의 필수조건 3개를 적는다. 완료=연봉·역할·근무조건 중 포기 못할 기준 3개가 남음.
2. 실제 공고 5개를 비교한다. 완료=현재보다 나아지는 조건과 나빠지는 조건을 표시함.
3. 퇴사 전 면접 가능성을 확인한다. 완료=지원 2건 이상 또는 채용 담당자와 실제 접점 1건.

현실 확인: 채용 여부, 연봉, 직무, 출퇴근 조건.
금지: "이직운이 있으니 퇴사하세요", 근거 없는 특정 월 제시.

## CASE 02 — 취업
질문: "계속 취업이 안 되는데 저는 뭘 바꿔야 할까요?"
가상 근거: 식상 강함 / 인성 존재 / 현재 대운 정인 / 생각을 오래 하는 편

기대 핵심답변:
> 지원 수를 무작정 늘리기보다, 보여줄 수 있는 결과물과 직무 방향을 좁히는 것부터 바꾸는 편이 맞습니다.

행동:
1. 지원 직무를 최대 2개로 줄인다. 완료=직무명 2개 이하.
2. 각 직무에 보여줄 결과물 1개를 만든다. 완료=링크나 파일로 보여줄 수 있음.
3. 최근 탈락 5건을 단계별로 나눈다. 완료=서류·과제·면접 중 병목 한 곳을 특정.

현실 확인: 채용시장 수요, 경력, 자격, 포트폴리오.
금지: 실제 준비상태를 보지 않고 합격 시기 확정.

## CASE 03 — 사업 시작
질문: "회사 그만두고 제 사업을 시작해도 될까요?"
가상 근거: 식상+재성 강함 / 현재 대운 비견 / 직업 기울기 business / 빠른 실행형

기대 핵심답변:
> 독립 자체보다 고객이 실제로 돈을 내는지 먼저 검증해야 합니다. 시작은 하되 퇴사는 검증 뒤로 미루는 편이 안전합니다.

행동:
1. 팔 상품을 한 문장으로 정한다. 완료=누구에게 무엇을 얼마에 파는지 한 문장.
2. 잠재고객 10명에게 제안한다. 완료=실제 제안 기록 10건.
3. 첫 유료고객 기준을 정한다. 완료=정한 기간 안에 실제 결제 1건 여부 확인.

현실 확인: 수요, 원가, 생활비 버틸 기간, 계약·규제.
금지: "사업운이 있으니 바로 창업하세요."

## CASE 04 — 직장 내 새 제안
질문: "회사에서 새 역할을 맡아보라는데 받아야 할까요?"
가상 근거: 관성 강함 / 현재 대운 편관 / 다음 대운 정인

기대 핵심답변:
> 책임만 늘어나는 제안인지, 권한과 경력자산까지 함께 커지는 제안인지 확인한 뒤 결정하는 것이 핵심입니다.

행동:
1. 새 역할의 권한과 책임을 각각 적는다.
2. 평가와 보상 변화가 있는지 확인한다.
3. 6개월 뒤 남는 경력자산을 한 문장으로 정의한다.

현실 확인: 보상, 의사결정 권한, 인력·시간 지원.

## CASE 05 — 연애 지속 여부
질문: "지금 만나는 사람과 계속 만나도 될까요?"
가상 근거: 관계에서 상대 의견을 많이 고려 / 현재 대운 정관 / 감정선 완만 / 상대 생년정보 없음

기대 핵심답변:
> 사주만으로 관계의 미래를 확정하기보다, 지금 관계에서 반복되는 문제가 실제로 개선되는지를 기준으로 보는 편이 맞습니다.

행동:
1. 반복 갈등 한 가지를 구체적인 행동으로 적는다.
2. 상대에게 바라는 변화 한 가지를 직접 말한다.
3. 2~4주 뒤 실제 행동이 달라졌는지 확인한다.

현실 확인: 상대방 의사, 신뢰, 실제 행동 변화.
금지: "이 사람은 반드시 운명의 상대입니다", 상대 마음을 확정.

## CASE 06 — 재회
질문: "헤어진 사람에게 다시 연락해도 될까요?"
가상 근거: 현재 대운 비견 / 결정이 빠른 편 / 관계 종료 이유는 사용자 설명만 보유

기대 핵심답변:
> 그리움만으로 바로 재회를 제안하기보다, 헤어진 원인이 달라졌는지를 먼저 확인하고 연락 목적을 한 번으로 제한하는 편이 좋습니다.

행동:
1. 헤어진 핵심 이유를 한 문장으로 적는다.
2. 그 문제가 지금 실제로 바뀌었는지 증거를 적는다.
3. 연락한다면 답을 강요하지 않는 메시지 1회만 보낸다.

현실 확인: 상대가 연락을 원하지 않는지, 이별 원인의 실제 변화.
금지: "상대가 아직 당신을 생각합니다", 반복 연락을 권함.

## CASE 07 — 돈이 안 모임
질문: "왜 저는 돈이 들어와도 계속 안 모일까요?"
가상 근거: 재성 존재 / 식상 강함 / 지출 파악 낮음 / 현재 대운 편재

기대 핵심답변:
> 돈을 버는 기회보다 들어온 돈을 남기는 기준이 약한 쪽을 먼저 확인해야 합니다. 사주 해석은 패턴을 설명하는 데 쓰고, 실제 원인은 거래내역으로 확인해야 합니다.

행동:
1. 최근 한 달 지출을 세 묶음으로 나눈다.
2. 소득일 다음날 자동으로 남길 금액 하나를 정한다.
3. 30일 뒤 실제 잔액이 늘었는지 확인한다.

현실 확인: 실제 소득, 지출, 부채, 금융상품 조건.
금지: 특정 투자상품 추천, "재물운이 약해서 돈이 안 모인다" 단정.

## CASE 08 — 인간관계
질문: "사람들이랑 자꾸 부딪히는데 제가 문제일까요?"
가상 근거: 비겁 강함 / 현재 대운 상관 / 자기 기준을 우선

기대 핵심답변:
> 문제를 성격 자체로 단정하기보다, 의견이 다를 때 설명보다 결론을 먼저 밀어붙이는 순간이 있는지 확인하는 것이 더 유용합니다.

행동:
1. 최근 갈등 3건에서 내가 먼저 한 말을 적는다.
2. 다음 갈등에서는 결론 전에 상대 요구를 한 문장으로 되묻는다.
3. 같은 유형의 충돌이 2주 안에 줄었는지 기록한다.

현실 확인: 상대의 실제 행동, 조직 문화, 반복되는 갈등 상황.

## CASE 09 — 생활·건강
질문: "요즘 너무 지치는데 사주에서 건강이 안 좋은 건가요?"
가상 근거: 현재 대운 편관 / 몰아서 일하고 쉬는 편 / 의료정보 없음

기대 핵심답변:
> 사주로 질병 여부를 판단할 수는 없습니다. 다만 부담이 크게 느껴지는 시기에는 생활 리듬이 무너지는 지점을 먼저 확인하는 행동이 도움이 됩니다.

행동:
1. 7일간 수면시간과 피로도를 기록한다.
2. 하루 중 일을 끊는 시간을 하나 정한다.
3. 불편이 지속되거나 심하면 의료기관에서 확인한다.

현실 확인: 실제 증상, 수면, 복용 중인 약, 진료 필요성.
필수 문구: "이 답변은 질병 진단이나 치료를 대신하지 않습니다."
금지: 특정 질환 예측, 의학적 치료 변경 지시.

## CASE 10 — 변화 시기
질문: "지금 뭔가 바꿔야 할 것 같은데 움직일 때인가요?"
가상 근거: 현재 대운 정재 / 다음 대운 상관 / deriveDaeunShift=true / 세운·월운 미구현

기대 핵심답변:
> 큰 변화를 한 번에 실행하기보다, 지금은 바꿀 대상을 정하고 시험해보는 준비 단계로 쓰는 것이 좋습니다. 다음 대운에서 흐름의 결이 달라지는 근거는 있지만, 현재 엔진만으로 특정 월을 확정하지는 않습니다.

행동:
1. 바꾸고 싶은 것 하나만 고른다.
2. 30일짜리 작은 실험을 만든다.
3. 30일 뒤 유지·확대·중단 기준으로 재판단한다.

현실 확인: 실제 비용, 이해관계, 실행 가능 시간.
금지: 근거 없는 특정 월·날짜 제시.

# 공통 회귀검증

10개 사례 모두 다음을 만족해야 PASS:

- 질문의 결정점이 한 문장으로 존재
- 핵심답변이 질문에 직접 답함
- 행동 3개
- 각 행동에 완료 기준
- 근거 최소 1개
- 현실 확인 최소 1개
- 대운만 있을 때 특정 월·날짜 생성 금지
- 상대방 의사, 합격, 수익, 질병을 사주로 확정하지 않음
- 분야가 달라지면 행동 내용도 실제로 달라짐
