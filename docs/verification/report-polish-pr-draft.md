# 손금 중복을 줄이고 프리미엄을 통합 연간 리포트로 제공

같은 손금 특징이 양손에서 검출되면 동일 문단을 두 번 생성하고 저장된 문장도 그대로 복원하던 문제를 수정합니다. 선별 관찰/해석을 한 번씩 보여주고, 재진입 시 관찰값에서 다시 구성합니다. 판독되지 않은 선은 해석하지 않으며 근거 없이 손금 주제를 5년 나이 구간에 순환 배정하던 표는 제거합니다.

프리미엄은 분야 선택 없이 총운·연애·재물·직장·12개월을 한 리포트로 제공합니다. 무료 복제·반복 행동 카드·고정 2주 과제를 줄이고 생활 속 행동 예시와 근거를 연결합니다. 공유는 양손 결과 또는 명시적 손금 건너뛰기 뒤에 표시합니다.

헤더와 본문을 포함한 프리미엄 요청 제한/취소, 늦은 응답 차단, 같은 탭의 재열람, 손금 실패 후 완료된 양손 관찰값 복원을 보완했습니다. 가격·결제·보상·수집 활성화는 포함하지 않습니다.

검증: 빌드·타입·변경 소스 lint PASS. 합성 입력 3개에서 무료 긴 문장 재사용 0, 12×4 계산 동일. Chromium에서 양손 순서·실제 30초 요청/본문 중단·취소·뒤로가기·재시도·재열람·공유 데이터 검증. 전체 lint는 기존 2 오류/5 경고이며 실제 iPhone/Android 손 카메라는 미검증입니다.
