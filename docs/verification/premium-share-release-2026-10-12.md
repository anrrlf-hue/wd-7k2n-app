## 프리미엄에서 달라진 읽기 순서

무료 성향 요약은 접힌 한 문장으로 남기고, 선택한 관심 분야의 **계산 근거 → 우선 행동 → 계획 변경 조건 → 연간 기간별 실행 → 필요할 때 고르는 보완 습관**이 드러나게 배치했다. 선택 근거를 우선 계획 옆에 한 번만 보여주고 기존 분야 본문에서는 반복하지 않는다. 프리미엄 진입 안내도 ‘무료보다 깊은 풀이’에서 행동·점검 일정의 설명으로 바꿨다.

계산 엔진, 월별 단계, 실험 선택 규칙을 추가로 바꾸지 않았다. 같은 권고는 분야별 2~3개 묶음으로 표시하고 모든 월의 근거를 보존한다. 무료와 프리미엄의 차이는 예측 정확도나 개인별 고유 문장 수가 아니라, 입력 근거에 연결된 행동 범위·전환 조건·기간 비교다.

예: 합성 입력 1988-12-02 06:15 여성, 일 관심 분야. 무료는 ‘작게 실행하며 자기 방법을 조정하는 편’이라는 성향을 설명한다. 프리미엄은 식상 2·관성 0의 비교를 근거로 **2주 안에 시안 1개, 이용자 1명, 수정점 2개, 시간 상한**을 정한다. 피드백이 역할 혼선으로 모이면 합의부터 다시 하고, 시간 상한을 넘기면 범위를 줄인다. 2026년 12월과 2027년 2~3월의 실험 권고는 한 번 묶되 2027년 1월 점검은 별도 기간으로 유지한다. 실제 일정과 기록이 월별 해석보다 우선이다.

## 실제 공유 문구와 URL

- 제목: `운·돈 · 무료 사주`
- 문구: `운·돈에서 내 사주를 무료로 살펴보세요. 성향·관계·일·재물의 흐름을 참고할 수 있어요.`
- URL: `https://saju-app-rouge.vercel.app/diagnosis?mode=free&focus=overall&start=free&from=share`

대표가 제공한 정식 주소를 기존 Vercel `saju-app` 프로젝트(`prj_FuqYCB9yIuFbPrZziGHjDw3bDBtB`)의 Production 별칭에서도 확인했다. 현재 페이지의 origin이나 출생정보 쿼리를 공유 주소로 복사하지 않는다. 공유 함수는 개인 결과를 인자로 받지 않으며 이름·출생일시·손 사진·상세 풀이·후속 문답을 URL 또는 공유 텍스트에 넣지 않는다. 공유 결과의 공개 저장소도 만들지 않았다.

일반 사주 결과와 관계 비교의 공유 동작은 같은 컴포넌트를 사용한다. 지원 브라우저에서는 ‘공유하기’로 기기 공유창을 열고, ‘링크 복사’와 직접 선택할 주소를 함께 제공한다. 카카오 SDK를 사용하거나 카카오 전달 완료를 확인한 것처럼 표시하지 않는다. 공유창 완료, 취소, 오류, 복사 완료, 복사 실패를 구분하며 취소 후 자동 복사하지 않는다. 이전 `relationship_share_created` 성공성 이벤트는 이 공유 동작에서 보내지 않는다.

수신자는 자신의 무료 사주 입력 단계로 진입한다. 기존 브라우저 저장 결과는 지우지 않으면서 이 진입에서는 복원하지 않는다. 예전 `/share/relationship#r=...` 링크는 조각을 읽거나 복호화·표시·전달하지 않고 주소 기록에서 제거한 뒤 무료 사주로 이동한다. 예전에 외부로 전달된 메시지 자체를 회수하는 기능은 아니다. 일반 결과의 이미지 저장은 그대로 두고 버튼 이름을 ‘내 사주 카드 이미지 저장’으로 명확히 했다.

## 배포 범위와 남은 정책

기존 손금 복구, 프리미엄 생성·표시, 개인정보 없는 서비스 초대 링크, 해당 검사·문서만 배포 대상이다. CI에는 새 프리미엄 검사를 추가하고 과거 커밋과의 비교를 위해 checkout의 전체 이력을 받도록 했다. 보호규칙을 우회하거나 강제 push하지 않는다. 원격 CI 결과, Production SHA 일치, 공개 URL에서의 같은 화면 검증은 배포 후 별도 결과로 남긴다.

프리미엄 무료 보기는 유지한다. 가격·결제·공유 보상·1인 1회 보상 판정·OAuth·새 유료 API·신년 상품 전환은 구현하지 않았다. 신년운세는 기존 사주·관계·상황 흐름을 유지하는 선택형 아이디어로만 남긴다. 전체 lint 성공, 실제 기기 카메라 성공, 사주의 과학적 예측 정확성을 주장하지 않는다.
