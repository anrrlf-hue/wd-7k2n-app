# 질문 → 사실 → 판단 → 행동 출력 계약

CONTENT_TRUST_CORRECTION. 기존 유료2의 미구현 통계 자리들은 근거 확보 전 사용하지 않는다.
새 유료 리포트/결제 기능을 구현한 문서가 아니다.

## 현재 무료 결과에 실제 연결된 항목

- 사용자 고민: 원문 인용. 진단 근거가 아니라 자기보고 걱정으로 표시.
- 재무 사실: 입력한 소득·고정지출·생활비·저축 범위. 자가 응답이며 거래내역 검증 완료로 표현하지 않음.
- 목적자금: 정확한 필요액·준비액·월 목표 배정액·기한. 미확인 시 NEEDS_CONFIRMATION.
- 준비 횟수: 남은 날짜를 평균 월 길이로 환산한 계획 추정. 실제 입금일·추가 지출로 재확인.
- 만기: 금리와 별개. 만기일·만기 잔액·상환 준비금으로 확인하며 월 상환액을 이자로 바꾸지 않음.
- 프리랜서: 낮은 달의 필수지출 부족분, 평균 잔여액, 높은 달과 낮은 달의 소득 폭.
- 관리방법: whatToDo / whatToRecord / whenToCheck / doneWhen. 사주 데이터는 사용하지 않음.
- 시뮬레이션: 점검을 이어가는 방식만 조정. 진단 우선순위를 변경하지 않음.

전체 설문 필드의 QUESTION / FACT / USED_BY / RESULT_EFFECT / ACTION_EFFECT 매핑:
`src/lib/survey-usage.ts`. 테스트가 실제 SurveyInput 필드와 1:1 대조한다.

## 자기정보 6문항

| 질문 | 사실 | 사용/결과 | 행동 |
|---|---|---|---|
| speed | 직접 답한 결정속도 | 비교 의미 분리·개인화 설명 | 실제 상황과 비교 |
| plan | 직접 답한 계획 선호 | 중립/미확인 유지·실행 방식 설명 | 계획을 적용할 상황 확인 |
| autonomy | 직접 답한 타인 영향 | 표현 모양/MBTI T/F와 투표 안 함 | 결정에 필요한 의견 범위 확인 |
| risk | 직접 답한 위험 선호 | 직접 응답 요약만 | 실제 감당 능력 별도 확인 |
| spendAwareness | 직접 답한 지출 체감 | 직접 응답 요약만 | 실제 내역과 대조 |
| savingConsistency | 직접 답한 저축 체감 | 직접 응답 요약만 | 입금/저축 내역과 대조 |

MBTI는 자기입력 유형의 설명일 뿐 사실 확인이나 금융 적합성 판단이 아니다.
출생정보는 기존 사주 계산에만 사용하며 재무 판정과 분리한다.
손금 사진은 실제 관찰된 선 정보만 사용하고 결정속도/관계영향으로 변환하지 않는다.

## 상담 근거 출력 제한

상담 출처가 없는 현재 상태에서 유사 고객 수, 평균 개선기간, 저축률 개선값, 효과 보장 문구는 출력하지 않는다.
추후 반입된 자료의 outcome=confirmed도 특정 개인의 측정 결과일 뿐 효능 일반화 근거가 아니다.
현재 연결점은 스키마와 질문 참조뿐이며 실제 상담 근거 적용은 TRUE_GAP이다.
